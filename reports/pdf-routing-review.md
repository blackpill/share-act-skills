# Smart PDF routing review

A separate read-only reviewer evaluated the updated Skill, PDF fixture and common setup/reuse wording.

1. Unique matching existing folder, readable content and permission: choose that folder within the confirmed scope; reuse the uploaded file and verify the authorized move before reporting success.
2. Multiple plausible folders: leave the upload unchanged, present verified candidates and ask the user.
3. Suggestive filename but unreadable content: do not classify from the filename alone; explain the limitation and ask.
4. No fitting existing folder: ask before filing; creating a folder needs explicit confirmation.
5. Previous document used A but current content fits B: reevaluate independently; use B when justified and authorized, never treat A as the default destination.

The root wording was tightened to distinguish fixed-target tasks from per-PDF clarification. No live documents were read or moved during this review.
